# Skyrim Upscaler — Skyrim 1.7.104 Compatibility Fork

**An experimental, AI-assisted fork of [PureDark's Skyrim Upscaler](https://github.com/PureDark/Skyrim-Upscaler), aimed at bringing compatibility with Skyrim Special Edition / Anniversary Edition 1.7.104.**

## About

This fork is being developed with the assistance of AI to adapt the original Skyrim Upscaler to the newer Skyrim runtime and Address Library V5.

The goal is to restore support for DLSS, FSR 2, and XeSS without downgrading Skyrim.

## Current Status

**Work in Progress — Experimental**

- Updated SKSE plugin version declarations.
- Integrated newer CommonLibSSE-NG with Address Library V5 support.
- Updated CMake configuration and dependencies.
- Added automated Windows x64 builds using GitHub Actions.
- Runtime compatibility and rendering hooks are not yet verified.

**Important:** Successful compilation does not guarantee that the plugin works in-game. This fork is not yet confirmed to work with Skyrim 1.7.104.
